# ATULYA JEEVAN

Quantum-Enhanced Medical Intelligence — visual research prototype.

## Run
npm install
npm run dev

Open http://localhost:3000

## Notes
This interface is a research/demo visualization. Model values shown in the UI are illustrative deterministic demo calculations, not clinical measurements or validated diagnostic predictions. Do not present them as measured quantum advantage or clinical performance.


## Theme fix
The day/night toggle uses semantic CSS variables so text, cards, borders, inputs, navigation and panels switch independently without black/white color inversion. Scientific visualization panels that are intentionally dark remain dark in both themes.
